From model to Minecraft.

  1. Open a preset or import your model. GeckoLib/Bedrock geometry, cube-based Blockbench models, and Hitbox+ profiles are supported.
  2. Fit the colored volumes. Click a box or select it in the list. Move, rotate or resize it, then assign a bone and body region.
  3. Preview the movement. Import numeric GeckoLib animations and bind clips to idle, walk, sprint, attack, death or swim.
  4. Export and install. Put a datapack ZIP in the world's datapacks folder, or put JSON in src/main/resources/data/your_mod/hitboxplus/profiles/. Reload datapacks with /reload.

Hitbox+ must be installed on the server and clients. GeckoLib rigs can activate through the exported profile. Custom renderer transforms, Molang and advanced animation controllers use the server adapter API. The editor never uploads your files.
