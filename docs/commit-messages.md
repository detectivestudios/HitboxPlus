# Commit message format

Use a short, plain-language subject describing the change, following the existing history:

```text
Organize repository documentation and community guides
Set up community issue forms and contribution guidance
```

- Start with a capitalized imperative verb, such as Add, Fix, Preserve, or Update.
- Name the affected behavior or area clearly.
- Use a single subject line for straightforward changes.
- Omit a trailing period, type prefixes such as `feat:`, and Markdown headings.
- Describe the changes included in the commit; do not claim validation that was not performed.

For example:

```text
Preserve body hit details in native projectile results
```

When a change needs more explanation, leave a blank line after the subject and add a concise
body explaining the reason, resulting behavior, and relevant validation.
